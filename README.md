# File Search Explorer v0.7.5

Windows向けのファイル検索・管理デスクトップアプリです。

## 1. 動作環境

- OS: Windows のみ対応（Windows 10 / 11 での動作を想定）
- インストーラー版を実行するだけで利用できます（追加のソフトウェアのインストールは不要です）

## 2. 主な機能一覧

- キーワードによるファイル・フォルダ検索（部分一致・完全一致・正規表現・あいまい検索）
- 拡張子指定・除外拡張子・除外フォルダ・サイズ範囲・更新日時／作成日時での絞り込み
- ファイル内容の全文検索（テキスト系ファイル）
- インデックス機能による高速検索（SQLite + FTS5）
- 検索結果の一覧表示・並べ替え・列表示のカスタマイズ・CSVエクスポート
- 検索結果からのプレビュー表示（テキスト／画像）とハッシュ値計算（MD5/SHA-1/SHA-256）
- 重複ファイル検索
- 検索条件のブックマーク・プリセット保存
- 検索速度履歴の記録・比較
- 検索完了時の通知（通知音・デスクトップ通知・アプリ内ポップアップ）
- ダークテーマ対応

## 3. 起動方法

インストーラーでインストール後、スタートメニューまたはデスクトップのショートカットから
「File Search Explorer」を起動してください。

## 4. データの保存場所

以下のフォルダにアプリのデータが保存されます。

```
%USERPROFILE%\.file_search_explorer\
```

- `settings.json` : アプリの設定
- `index.db` / `index.db.enc` : 検索インデックス（終了時に暗号化されます）
- `session_state.json` : 前回終了時の状態
- `app_errors.log` : エラーログ

## 5. 注意事項

- Windows専用のアプリです（Linux・macOSには対応していません）。
- インデックスDBはアプリ終了時に暗号化されます。異常終了した場合、次回起動時に
  自動で整合性チェックが行われます。
- 実行ファイル（.exe や .bat など）を開く際は、誤操作防止のため必ず確認ダイアログが表示されます。
- システムフォルダ（Windows、Program Files など）は重複ファイル検索の対象にできません。

## 6. 主なキー操作

| キー | 動作 |
|---|---|
| Ctrl + T | 新しいタブを開く |
| Ctrl + W | 現在のタブを閉じる |
| Ctrl + L | 検索フォルダ欄にフォーカス |
| Ctrl + F | キーワード欄にフォーカス |
| F5 | 検索を実行 |
| Esc | 実行中の検索を停止 |

## v0.7.5 での変更点

- ステータスバーの検索進捗（予測残り時間・件数）の表示が崩れる不具合を修正しました。
  - 複数フォルダを同時に検索したとき、2フォルダ目以降で進捗表示が
    「残り0%」のまま動かなくなっていた問題を修正（フォルダ横断で予測値を合算するよう変更）。
  - 想定より検索が長引いた場合でも、実際に完了するまでは「残り0%」と表示されないよう改善。
- 予測時間・予測件数が実際の結果と大きくズレる問題を修正しました。
  - これまでは「同じフォルダ・同じ検索方式」というだけで、内容検索の有無や
    拡張子指定などの検索条件が違っていても過去の記録をそのまま予測に使い
    回していたため、条件が変わるたびに予測が大きく外れていました。
    検索条件が一致する記録だけを予測に使うよう修正しています（条件が一致する
    過去の記録がない場合は、無理に予測値を出さず「予測なし」の表示になります）。
  - 複数フォルダを同時に検索したとき、合計の所要時間・件数が1フォルダ目の
    名前でまとめて記録されてしまい、後の予測を狂わせていた問題も修正しました。
    フォルダごとに検索が完了するたびに、そのフォルダだけの実績として記録するよう変更しています。
  - 環境要因による記録のブレを減らすため、直近1件だけでなく直近最大3件の平均を予測値として使うようにしました。
  - **検索履歴が無くても、その場で直接計算できる値は計算して使うようにしました。**
    インデックス検索では、検索を始める前にインデックスDBへSQLのCOUNTクエリを直接投げて
    候補件数を算出します（履歴不要）。通常検索(インデックス未使用)では、ファイル名の
    判定を行わない軽量な「件数だけ数えるスキャン」を検索と並走させ、実際にスキャンした
    件数の割合から「このペースならあと何秒かかりそうか」をリアルタイムに逆算します
    （これも履歴不要）。過去の検索履歴は、これらの実測値が使えない場合の補助的な
    フォールバックという位置づけになりました。
- 配布用exeにバージョン情報（会社名・製品名・バージョン番号など）を埋め込めるようにしました
  （開発者向け: 下記「exeへのバージョン情報埋め込み」参照）。

## 開発者向け情報

### exeへのバージョン情報埋め込み

同梱の `version_info.txt` を使うと、PyInstallerでビルドしたexeのプロパティ（詳細タブ）に
バージョン番号・会社名・製品名などを表示できます。

```
pyinstaller --onefile --noconsole ^
    --collect-all tkinterdnd2 --collect-all plyer ^
    --version-file=version_info.txt ^
    --name FileSearchExplorer file_search_explorer.py
```

バージョンを更新する際は、`file_search_explorer.py` の `APP_VERSION` と
`version_info.txt` 内の `filevers` / `prodvers` / `FileVersion` / `ProductVersion` を
必ず合わせて更新してください。

### 依存パッケージ（開発・ビルド時のみ）

`requirements.txt` を参照してください（cryptography, pyinstaller, Pillow, plyer, tkinterdnd2）。
配布用インストーラーにはこれらのパッケージが同梱されているため、利用者側でのインストール作業は不要です。
