# File Search Explorer

Windows向けのデスクトップファイル検索・管理アプリケーションです。

現在のバージョン: **v0.8.2**

## 概要

- ファイル名検索（部分一致・完全一致・正規表現・あいまい検索）
- ファイル内容検索（テキスト系ファイル）
- インデックス検索（SQLite + FTS5による高速検索）
- 重複ファイル検索（ハッシュ比較）
- 検索結果のプレビュー・CSVエクスポート
- ダーク/ライトテーマ、検索条件の保存、ブックマーク 等

本アプリは完全オフラインで動作します。外部への通信・検索キーワードや
ファイル情報の送信は一切行いません。

## 動作環境

- Windows 10 / 11

## インストール

配布されているインストーラーをダウンロードし、実行してください。
Python環境の別途インストールは不要です（PyInstallerによるスタンドアロン配布）。

## v0.8.2の主な変更点

検索エンジンの安定性向上を目的としたリリースです。

1. 内容検索中のファイル削除・移動、停止操作への応答性を改善
2. アクセス拒否されたフォルダ・ファイルの件数管理にメモリ保護の上限を追加
3. 壊れたファイル・特殊なリパースポイント等でインデックス作成/検索全体が
   停止してしまう不具合を修正
4. 大量のサブフォルダを含む環境での検索停止操作の応答性を改善
5. 大量の検索結果を扱う際のメモリ使用量を保護する仕組みを強化

詳細はQiitaの技術記事をご参照ください。
