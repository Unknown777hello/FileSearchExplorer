File Search Explorer
Windows向けのデスクトップファイル検索・管理アプリケーションです。

ファイル名・フォルダ名・ファイル内容をローカル環境で検索できます。検索結果の絞り込み、プレビュー、ハッシュ計算、重複ファイル検索、CSVエクスポートなどに対応しています。

現在のバージョン：v0.8.6

対応環境
Windows 10

Windows 11

64-bit Windowsを優先対応

SmartScreenについて
新しく公開されたWindowsアプリやインストーラーでは、Microsoft Defender SmartScreenに「WindowsによってPCが保護されました」などの警告が表示される場合があります。

これは、ファイルの安全性が確認されたことを意味するものでも、危険であることを意味するものでもありません。実行する前に、次の項目を確認してください。

ダウンロード元が公式配布先であること。

ファイル名が公式リリースと一致していること。

ファイルのハッシュ値が公開値と一致していること。

デジタル署名がある場合、発行元が想定した開発者であること。

新しい署名済みファイルでも、SmartScreenの評価が蓄積するまで警告が表示される場合があります。MicrosoftはSmartScreenで署名情報とファイルの評価を使用すると説明しています。［］

基本的な使い方
検索対象のフォルダを選択します。

キーワードを入力します。

必要に応じて検索条件を設定します。

F5キーを押すか、検索ボタンをクリックします。

検索結果を確認します。

必要に応じて、プレビュー、ファイルを開く、CSVエクスポートなどを実行します。

検索モード
部分一致
ファイル名またはフォルダ名に、入力したキーワードが含まれる項目を検索します。

完全一致
ファイル名またはフォルダ名が、入力したキーワードと一致する項目を検索します。

正規表現
正規表現を使用してファイル名やフォルダ名を検索します。

正規表現の構文が正しくない場合、一致する結果が表示されないことがあります。

あいまい検索
入力キーワードと名前の近さを基準に、軽微な入力ミスや表記揺れを含む項目を検索します。

ファイル内容検索
対応するテキストファイルの内容を検索できます。

対応する文字コードの例：

UTF-8

UTF-8 BOM付き

CP932

UTF-16 LE

UTF-16 BE

バイナリファイル、破損したファイル、対応していない形式のファイルは内容検索の対象外になる場合があります。

ファイル内容検索には、対象ファイルの読み取り権限が必要です。

インデックス検索
インデックス検索を有効にすると、作成済みのSQLiteインデックスを利用して高速に検索できます。

インデックスには、検索対象となったファイルやフォルダの情報が含まれる場合があります。インデックス作成には、対象フォルダへの読み取り権限が必要です。

ファイルの移動、削除、名前変更などが行われた場合、インデックスの内容が現在のファイルシステムと一致しないことがあります。その場合は、インデックスを更新してください。

データの取り扱い
本アプリの公式ビルドには、開発者へのテレメトリ、広告、アップデート確認、検索データの外部送信機能は含まれていません。

検索処理、ファイル内容の読み取り、ハッシュ計算、インデックス作成は、利用者の端末上で実行されます。

本アプリは、検索対象のファイルを開発者のサーバーへアップロードしません。

ただし、OS、ウイルス対策ソフト、バックアップソフト、クラウド同期ソフトなど、他のソフトウェアによる通信や処理は、本アプリの管理対象外です。

アプリ設定

セッション状態

検索条件

キーワード履歴

最近使用したフォルダ

検索結果の一時情報

これらには、ファイル名、フォルダ名、ファイルパス、検索条件などが含まれる場合があります。

「開発者がデータを取得しない」ことと、「アプリが端末内にデータを保存しない」ことは異なります。

保存場所
通常、データは次の場所に保存されます。

text
%USERPROFILE%\.file_search_explorer\
├── settings.json          設定ファイル
├── session_state.json     セッション状態
├── index.db               復号中に使用されるインデックスDB
├── index.db.enc           暗号化されたインデックスDB
├── index.key              インデックス暗号化キー
└── app_errors.log         エラーログ
インデックスの暗号化
インデックスDBは暗号化して保存されます。

ただし、復号に必要な暗号鍵も利用者の端末内に保存されます。そのため、暗号化機能はインデックスDBの保存時の秘匿性を高めるためのものであり、端末やユーザーアカウントが侵害された場合の完全な保護を保証するものではありません。

設定ファイル、インデックスDB、暗号鍵などには、対応する環境で可能な範囲のアクセス権制限が適用されます。

利用上の注意
本アプリは、利用者がアクセス権を持つファイルおよびフォルダを検索する目的で使用してください。

次の目的で使用しないでください。

他人の端末を無断で検索すること。

他人のアカウントやフォルダへ無断でアクセスすること。

ネットワーク共有やクラウドストレージを権限なく検索すること。

OSやアプリケーションのアクセス制御を回避すること。

他人のファイルを無断で閲覧、取得、変更、削除すること。

利用者は、検索対象および操作対象に対する適切な権限を自ら確認してください。

ファイルを開く操作
検索結果からファイルやフォルダを開くことができます。

実行ファイルやスクリプトを開く場合は、確認ダイアログが表示されます。

対象となる拡張子の例：

.exe

.bat

.cmd

.ps1

.vbs

.js

.jar

実行ファイルやスクリプトには、悪意のあるコードが含まれている可能性があります。ファイルの出所、署名、内容を確認してから操作してください。

本アプリは、ファイルの安全性や信頼性を保証するものではありません。

削除操作
Windows、Program Files、ProgramDataなど、一部のシステム関連フォルダへの削除操作は、安全対策としてブロックされます。

ただし、この保護機能はすべての重要ファイルや重要フォルダの削除を防止するものではありません。

削除操作を実行する前に、次の項目を確認してください。

対象のファイル名

対象のフォルダ

削除対象の件数

必要なバックアップの有無

削除されたファイルの復元は保証されません。

CSVエクスポート
検索結果をCSV形式で保存できます。

CSVファイルには、次の情報が含まれる場合があります。

ファイル名

フォルダ名

ファイルパス

ファイルサイズ

更新日時

検索結果に関する情報

CSVファイルを共有または公開する前に、個人情報、機密情報、社内情報が含まれていないか確認してください。

ハッシュ値
対応するハッシュアルゴリズム：

MD5

SHA-1

SHA-256

MD5およびSHA-1は、強い改ざん検出やセキュリティ用途には適さない場合があります。安全性を重視する用途では、SHA-256などを使用してください。

ハッシュ値はファイルの内容に基づく識別情報です。ハッシュ値だけで、ファイルが安全であること、信頼できること、または悪意のあるコードを含まないことを保証するものではありません。

インストーラー版には、実行に必要なPythonランタイムおよび必要な依存ファイルが含まれる場合があります。

PyInstallerの公式ドキュメントでは、PyInstallerで生成した実行ファイルを独自のライセンスで配布できる一方、依存ライブラリのライセンス条件には従う必要があると説明されています。［］

既知の制限
Windows以外では、動作や表示が正しくない場合があります。

アクセス権のないファイルやフォルダは検索できない場合があります。

検索中にファイルが移動、削除、変更された場合、結果が現在の状態と一致しない場合があります。

大量のファイルを検索すると、完了まで時間がかかる場合があります。

ネットワークドライブでは、接続状態やアクセス権により動作が異なる場合があります。

シンボリックリンク、ジャンクション、特殊なファイルシステムでは、検索結果が想定と異なる場合があります。

画像プレビュー、ドラッグ＆ドロップ、暗号化、デスクトップ通知などは、ビルド内容や環境により利用できない場合があります。

SmartScreenやウイルス対策ソフトによって、未知のアプリとして警告される場合があります。
