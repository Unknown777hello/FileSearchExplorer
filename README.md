# File Search Explorer v0.7.2

Windows標準の検索より速く、ラクにファイルを探すためのデスクトップ検索アプリです。

## 1. 動作環境

- Windows 10 / 11 (64bit)
- インストーラーで必要なファイルはすべてまとめて導入されるため、別途Pythonや追加ライブラリを用意する必要はありません。

## 2. 主な機能一覧

- **タブ切り替え**：複数のフォルダを並行して検索できます
- **爆速インデックス検索**：一度インデックスを作成したフォルダは、2回目以降の検索が高速になります
- **簡易プレビュー**：ファイルを選択するだけで、中身（テキスト/画像）を確認できます
- **ファイル内容検索**：テキスト系ファイルであれば、中身に含まれる文字列でも検索できます
- **詳細検索**：一致方法（部分一致/完全一致/正規表現/あいまい検索）、AND・OR・NOT検索、除外フォルダ、サイズ範囲、更新日時・作成日時範囲などで絞り込めます
- **検索テンプレート／検索条件の保存（プリセット）**：よく使う条件をワンクリックで呼び出せます
- **重複ファイル検索**：内容が同じファイルをハッシュ比較で検出し、まとめて整理できます
- **ダークモード**：ライト/ダークをお好みで切り替えられます
- **検索結果のエクスポート**：CSV形式で書き出せます
- **検索完了時の通知**：通知音、デスクトップ通知、アプリ内ポップアップに対応
- **設定の自動記憶**：検索フォルダ、各種チェックボックス、ウィンドウサイズなどを次回起動時にも自動で復元します

## 3. 起動方法

インストール後、スタートメニューまたはデスクトップのショートカットから「File Search Explorer」を選択して起動してください。

起動直後は画面がすぐに表示されます。インデックス検索やインデックス管理を初めて使うタイミングで、インデックスデータベースの準備が一度だけ行われます（検索フォルダの規模によっては数秒かかる場合があります）。

## 4. データの保存場所

検索設定やインデックスデータは、以下のフォルダに保存されます。

```
%USERPROFILE%\.file_search_explorer\
```

主なファイル：

| ファイル | 内容 |
|---|---|
| `settings.json` | 検索条件や画面設定など |
| `index.db.enc` | 暗号化されたインデックスデータベース（アプリ終了時に暗号化されます） |
| `app_errors.log` | エラーが発生した場合の記録 |

このフォルダを削除すると、設定とインデックスはすべて初期化されます。

## 5. 注意事項

- インデックス検索を初めて使う際、フォルダの規模によってはインデックス作成に時間がかかる場合があります。作成中も他の操作は可能です。
- 作成日時での絞り込みは、現時点ではインデックス検索に対応していません。作成日時を指定した場合は自動的に通常検索（フォルダを直接走査する方式）に切り替わります。
- 重複ファイル検索での「完全に削除」操作は、ゴミ箱を経由せず元に戻せません。実行前に必ず対象ファイルの一覧をご確認ください。
- Windowsのシステムフォルダ（Windows、Program Files、ProgramData など）は、誤削除防止のため重複ファイル検索の対象にできません。
- データベースの整合性チェックは、初回起動時・前回異常終了時・手動でのデータベース修復実行時、およびおおむね月1回のペースで自動的に行われます。

## 6. 主なキー操作

| キー | 操作 |
|---|---|
| `Ctrl + T` | 新しいタブを開く |
| `Ctrl + W` | 現在のタブを閉じる |
| `Ctrl + L` | 検索フォルダ欄にフォーカスを移動 |
| `Ctrl + F` | キーワード欄にフォーカスを移動 |
| `F5` | 現在の条件で検索を実行 |
| `Esc` | 実行中の検索を停止 |
