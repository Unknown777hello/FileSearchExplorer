# File Search Explorer

Windows / macOS / Linux で動作する、Tkinter製の高機能ファイル検索デスクトップアプリです。
フォルダを指定してファイル名・フォルダ名・ファイル内容を検索し、結果の絞り込み・エクスポート・重複ファイル検出などを行えます。

---

## 主な機能

### 検索
- ファイル名・フォルダ名のキーワード検索（部分一致 / 完全一致 / 正規表現 / あいまい検索）
- キーワード欄で `AND` / `OR` / `NOT` を使った複数語句の組み合わせ検索
- ファイル内容の検索（テキスト系拡張子が対象。バイナリファイルは自動除外）
- 拡張子指定・除外拡張子、除外フォルダ（カンマ区切り）
- ファイルサイズ範囲、更新日時範囲、作成日時範囲での絞り込み
- 複数フォルダをまとめて検索
- サブフォルダ再帰検索、隠し/システムファイルの表示切り替え
- よく使う検索条件の「テンプレート」（画像・動画・音楽・文書・圧縮ファイル・実行ファイル・コード）
- 検索条件のプリセット保存・読み込み・JSONエクスポート/インポート
- お気に入りフォルダ・最近使用したフォルダの履歴
- 検索結果に対するリアルタイム絞り込み（再検索なし）
- 結果の表示列（フォルダ／サイズ／更新日時／内容一致箇所）のカスタマイズ
- 大量件数でもスクロールが軽い仮想スクロール表示
- 検索結果のCSVエクスポート

### インデックス検索（高速化）
- あらかじめフォルダをインデックス化しておくことで、次回以降の検索を高速化
- インデックスDBは自動的に暗号化されて保存されます（`cryptography` パッケージが必要）
- 差分更新（変更されたファイルのみ再登録、削除されたファイルは自動除外）
- インデックス管理画面から、追加・更新・削除・DB最適化（VACUUM）・不要ルートの整理が可能
- 入力するたびに自動で再検索する「ライブ再検索」モード（任意でON/OFF）
- キーワード欄の入力候補をインデックスから自動提案

### 重複ファイル検索
- サイズ＋ハッシュ値（SHA-256）による重複ファイルの検出
- 拡張子・最小サイズでの絞り込み
- 検出結果から選択したファイルを完全削除（誤操作防止の確認ダイアログつき）
- Windows/Program Files 等のシステム保護フォルダは検索対象外

### プレビュー・その他
- テキスト/画像ファイルの簡易プレビュー（設定でON/OFF切り替え可能）
- MD5 / SHA-1 / SHA-256 のファイルハッシュ計算
- 検索完了時の通知（通知音・デスクトップ通知・アプリ内ポップアップ）
- ライト/ダークテーマ切り替え
- 検索フォルダへのドラッグ&ドロップ対応（`tkinterdnd2` が必要）
- 検索速度の履歴表示（前回検索との比較付き）
- アクセス権限エラーのあったフォルダ一覧表示・再確認機能
- 複数タブでの並行検索

## 動作環境

- Windows / macOS / Linux 対応
- **インストーラをご利用の場合、必要なライブラリはすべて同梱済みです。追加のインストール作業は不要です。**

<details>
<summary>参考：ソースコードから直接実行する場合（開発者向け）</summary>

Python 3.9 以降と、標準ライブラリの `tkinter` が使用できる環境が必要です。

- Windows/macOS の公式インストーラには `tkinter` が通常同梱されています
- Linux の場合、`sudo apt install python3-tk` 等が必要な場合があります

以下の追加パッケージを導入するとフル機能が使えます（無くても起動・動作はします）。

| パッケージ | 用途 | 無い場合の挙動 |
|---|---|---|
| `cryptography` | インデックスDBの暗号化 | インデックス機能自体は動作しますが、DBは暗号化されず平文で保存されます |
| `Pillow` | 各種画像フォーマットのプレビュー | PNG/GIF等の一部形式のみ簡易プレビュー可能 |
| `tkinterdnd2` | フォルダのドラッグ&ドロップ | ドラッグ&ドロップ機能が無効になります |
| `plyer` | デスクトップ通知 | 通知音・アプリ内ポップアップのみ利用可能 |
| `winsound`（Windows標準） | 通知音再生 | Windows以外では自動的にスキップされます |

```bash
pip install -r requirements.txt
```

</details>

## 起動方法

インストーラで導入した場合は、通常のアプリと同じようにアイコンから起動してください。

ソースコードから直接実行する場合：

```bash
python file_search_explorer.py
```

---

## 使い方（概要）

1. 「検索フォルダ」に検索したいフォルダを指定（「参照...」ボタンからも選択可）
2. 「キーワード」に探したいファイル名の一部を入力
3. 「🔍 検索開始」をクリック
4. 必要に応じて「▶ 詳細検索・その他の条件」を開き、拡張子・サイズ・日付などで絞り込み
5. 結果は一覧から「開く」「フォルダを開く」「パスをコピー」などが可能（右クリックメニューあり）

高速に何度も検索する場合は、「インデックス管理」から対象フォルダを事前にインデックス化し、
検索条件の「インデックスを使用する(高速)」にチェックを入れてください。

## データの保存場所

設定・インデックス・ログは、OSごとのユーザーホームディレクトリ配下の `.file_search_explorer` フォルダに保存されます。

```
<ユーザーホーム>/.file_search_explorer/
├── settings.json      # アプリ設定
├── index.db.enc        # 暗号化されたインデックスDB（cryptography導入時）
├── index.key           # 暗号化キー
└── app_errors.log      # エラーログ
```

インデックスに不具合が出た場合は、`index.db*` 関連ファイルを削除すればアプリが自動的に再作成します（検索設定やブックマーク等は失われません）。

---

## 注意事項

- 重複ファイル検索の「削除」は**ゴミ箱を経由しない完全削除**です。実行前に一覧を必ず確認してください。
- 拡張子が実行ファイル・スクリプト系（`.exe` `.bat` `.ps1` `.js` など）のファイルを開く際は、確認ダイアログが表示されます。
- macOS/Linuxでは、ファイルの「作成日時」が正確に取得できない場合があります（OS/ファイルシステムの仕様上の制約）。
