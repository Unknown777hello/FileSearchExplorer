# File Search Explorer

Windows向けのファイル検索・管理デスクトップアプリです。フォルダ配下のファイルを高速に検索し、プレビュー・重複検索・インデックス管理などをまとめて行えます。

現在のバージョン: **v0.8.3**

## 動作環境

- Windows 10 / Windows 11(Pythonは不要です)

## 主な機能一覧

- ファイル名・フォルダ名検索（部分一致・完全一致・正規表現・あいまい検索）
- ファイル内容検索（テキスト系ファイル、UTF-8/CP932/UTF-16対応）
- インデックス検索（SQLite + FTS5による高速検索、複数フォルダ対応）
- 詳細検索条件（拡張子・除外フォルダ・サイズ範囲・更新日時/作成日時範囲）
- 複数フォルダの同時検索、検索条件のプリセット保存・JSONエクスポート/インポート
- 検索結果のプレビュー表示（テキスト・画像）、ハッシュ値計算（MD5/SHA-1/SHA-256）
- 検索結果のCSVエクスポート
- 重複ファイル検索（サイズ→ハッシュの2段階比較）
- 大量検索結果向けの仮想スクロール表示
- 検索完了時の通知（音・デスクトップ通知・アプリ内ポップアップ）
- 検索速度履歴の記録・表示
- ライト/ダークテーマ切り替え

## v0.8.3 の変更点（仮想スクロール・大量データ対応）

- 結果の絞り込み入力をデバウンス化し、大量結果でも入力中のもたつきを軽減
- 大量検索結果（既定5万件超）のソートをバックグラウンドスレッドで実行
- 仮想スクロールの差分更新に重なり率のしきい値判定を追加し、非効率な差分更新を回避
- 仮想スクロールの再描画デバウンス間隔をシステム性能に応じて動的に調整
- Treeviewの全体再構築時、一時的に非表示にして中間描画コストを抑制

過去のバージョン（v0.8.0〜v0.8.2）ではインデックスDBの暗号化・設定ファイルの保存耐障害性・検索エンジンの安定性を中心に改善しています。

## 起動方法

配布されているインストーラを実行し、案内に従ってインストールしてください。インストール後はスタートメニューまたはデスクトップのショートカットから起動できます。

## データの保存場所

以下のフォルダにアプリのデータが保存されます。

```
%USERPROFILE%\.file_search_explorer\
├─ settings.json          設定ファイル（.bakバックアップ付き）
├─ session_state.json     セッション状態
├─ index.db.enc           暗号化されたインデックスDB（起動中は復号されindex.dbとして存在）
├─ index.key              インデックスDB暗号鍵
└─ app_errors.log         エラーログ（個人を特定できる情報はマスキング済み）
```

本アプリは完全にオフラインで動作します。検索キーワードやファイル情報を含む、いかなる情報も外部へ送信しません。

## 注意事項

- 検索対象や重複ファイルの削除操作は元に戻せません。削除前に内容を必ずご確認ください。
- Windows・Program Files など、システム関連フォルダ内のファイル削除・重複検索は安全のため制限されています。
- インデックス検索は事前にインデックスを作成したフォルダのみ対象になります。索引作成後に変更されたファイルは、次回のインデックス更新まで反映が遅れる場合があります。

## 主なキー操作

| キー | 動作 |
| --- | --- |
| Ctrl+T | 新しいタブを開く |
| Ctrl+W | 現在のタブを閉じる |
| Ctrl+F | キーワード欄にフォーカス |
| Ctrl+L | フォルダ欄にフォーカス |
| F5 | 検索を実行 |
| Esc | 検索を停止 |
