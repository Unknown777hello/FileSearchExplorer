# File Search Explorer v0.7.7

Windows向けの高速ファイル検索・管理ツールです。キーワード検索、インデックスによる高速検索、重複ファイル検索、簡易プレビューなどをひとつのアプリにまとめています。

## 1. 動作環境

- Windows 10 / Windows 11 (64bit)
- 追加のソフトウェアのインストールは不要です(インストーラーに必要なファイルがすべて含まれています)
- メモリ 4GB 以上を推奨(大量のファイルを検索・インデックス化する場合はメモリ・CPUコア数が多いほど高速に動作します)

## 2. 主な機能一覧

- **キーワード検索**: 部分一致 / 完全一致 / 正規表現 / あいまい検索(誤字補正)、AND / OR / NOT の複合条件
- **絞り込み条件**: 拡張子指定・除外拡張子、ファイルサイズ、更新日時・作成日時の範囲
- **内容検索**: テキスト系ファイルの中身を検索
- **複数フォルダ検索**: 複数フォルダをまとめて検索対象にできる
- **インデックス検索**: あらかじめフォルダを索引化しておくことで2回目以降の検索を高速化(SQLite + FTS5利用)
- **検索結果操作**: 結果内絞り込み、列の表示/非表示切り替え、並び替え、CSVエクスポート
- **プレビュー**: テキスト・画像の簡易プレビュー、ハッシュ値計算(MD5/SHA-1/SHA-256)
- **重複ファイル検索**: 内容が同一のファイルをハッシュ比較で検出
- **利便性機能**: お気に入りフォルダ、最近使ったフォルダ、検索条件プリセットの保存
- **通知**: 検索完了時の通知音・デスクトップ通知・アプリ内ポップアップ
- **検索速度履歴**: 過去の検索の所要時間・件数を記録・比較
- **複数タブ**での同時検索、**ライト/ダークテーマ**切り替え、**ドラッグ&ドロップ**対応

## 3. 起動方法

1. インストーラーを実行し、画面の指示に従ってインストールします。
2. インストール完了後、デスクトップまたはスタートメニューの「File Search Explorer」アイコンから起動します。

## 4. データの保存場所

以下のフォルダにアプリの設定・インデックスデータが保存されます。

```
%USERPROFILE%\.file_search_explorer\
├─ settings.json      … アプリの設定
├─ index.db.enc         … 暗号化されたインデックスデータベース
└─ app_errors.log        … エラーログ(不具合調査用)
```

このフォルダを削除すると、設定やインデックスはすべて初期化されます。

## 5. 注意事項

- 実行ファイル(`.exe`, `.bat` など)を開く際は、誤操作防止のため確認ダイアログが表示されます。内容をよく確認してから実行してください。
- Windows や Program Files などのシステムフォルダは、誤削除防止のため重複ファイル検索の対象にできません。
- 非常に大きなフォルダ(数十万件以上)を検索すると、検索結果一覧に保持できる件数に上限があります(上限を超えた分は件数のみ集計されます)。
- インデックスデータベースは終了時に自動的に暗号化されます。アプリの異常終了が続いた場合は、次回起動時にデータベースの整合性チェックが自動的に行われます。

## 6. 主なキー操作

| キー | 動作 |
| --- | --- |
| `Ctrl + T` | 新しいタブを開く |
| `Ctrl + W` | 現在のタブを閉じる |
| `Ctrl + L` | 検索フォルダ欄にカーソルを移動 |
| `Ctrl + F` | キーワード欄にカーソルを移動 |
| `F5` | 検索を実行 |
| `Esc` | 実行中の検索を停止 |
