# FileSearchExplorer

**オフラインで使えるファイル検索**

Windows 10 / 11で使える、無料のファイル検索ソフトです。

**ファイル名だけでなく、ファイルの中身まで検索できます。**

大量のファイルの中から、目的のファイルを探したいときに使用できます。

## ダウンロード

最新版はGitHub Releasesからダウンロードできます。

[最新版をダウンロード](https://github.com/Unknown777hello/FileSearchExplorer/releases/latest)

### インストール

1. 最新版のReleasesページを開く
2. `FileSearchExplorer_Setup_*.exe` をダウンロードする
3. ダウンロードしたインストーラーを実行する

**Pythonのインストールは必要ありません。**

## こんなときに使えます

* ファイル名を忘れてしまった
* パソコンの中から特定のファイルを探したい
* ファイルの中に書かれている文字から探したい
* 同じファイルが複数ないか確認したい
* Windows標準の検索だけでは足りない
* 複雑な条件でファイルを検索したい

## 主な機能

* ファイル名検索
* ファイル内容検索
* AND検索
* OR検索
* NOT検索
* 正規表現検索
* あいまい検索
* 重複ファイル検索
* ファイルプレビュー
* ドラッグ＆ドロップ
* 検索結果の出力
* ダークモード
* 簡単な検索
* 高度な検索

## 簡単な検索

普段のファイル検索には、簡単な検索を使用できます。

検索場所と検索する文字を指定するだけで、ファイルを探せます。

## 高度な検索

より細かい条件を指定したい場合は、高度な検索を使用できます。

AND・OR・NOT・正規表現・あいまい検索などを利用して、条件を細かく指定できます。

## ファイルの中身を検索

ファイル名が分からなくても、ファイルの中に書かれている文字から検索できます。

「どこに保存したか分からない」「ファイル名を忘れた」という場合にも、目的のファイルを探せます。

## 重複ファイル検索

パソコン内にある重複したファイルを探せます。

同じファイルが複数の場所に保存されていないか確認したい場合に使用できます。

## 完全オフラインで使用

FileSearchExplorerは、パソコン内のファイルを検索するソフトです。

インターネット上のサービスにファイルをアップロードして検索する方式ではありません。

完全オフライン環境でも使用できます。
