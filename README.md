# File Search Explorer

Windows向けのファイル検索・管理デスクトップアプリです。高速なファイル名検索に加え、
インデックスを使った検索、ファイル内容検索、重複ファイル検索などの機能を備えています。

現在のバージョン: **v0.7.6**

## 動作環境

- OS: Windows 10 / 11 (64bit)
- インストーラーに必要なファイルがすべて同梱されているため、追加のソフトウェアの
  インストールは不要です。
- 本アプリは Windows 専用です。Windows 以外の環境ではご利用いただけません。

## 主な機能一覧

- ファイル名検索（部分一致・完全一致・正規表現・あいまい検索（誤字補正）に対応）
- ファイル内容検索（テキスト系ファイルの中身も検索）
- インデックス検索：あらかじめ作成した索引を使った高速検索
  - 検索の下地となるSQLiteデータベースを最適化し、大規模なフォルダでも
    スムーズに検索できます
  - 対応環境では、より高速な部分一致検索（トライグラム方式）を自動的に利用します
- 検索処理の並列化：フォルダの規模に応じて自動的に複数の処理を同時に走らせ、
  検索時間を短縮します（小規模フォルダでは自動的に従来方式で動作します）
- 検索結果一覧の表示強化：数万件規模の検索結果でも、スクロールがなめらかに
  動作するよう最適化しています
- 複数タブでの同時検索
- お気に入りフォルダ・最近使ったフォルダ・検索条件プリセットの保存
- 拡張子・サイズ・更新日時・作成日時などによる詳細な絞り込み
- 重複ファイル検索（内容が同一のファイルをハッシュ比較で検出）
- 検索結果のCSVエクスポート
- ダーク／ライトテーマの切り替え
- 検索完了時の通知（通知音・デスクトップ通知・アプリ内ポップアップ）
- フォルダのドラッグ＆ドロップによる検索対象指定
- 検索インデックスの暗号化保存（終了時に自動的に暗号化されます）

## 起動方法

インストーラーでインストール後、スタートメニューまたはデスクトップのショートカット
から「File Search Explorer」を起動してください。

## データの保存場所

検索インデックス・設定ファイル・アプリのログは、以下のフォルダに保存されます。

```
%USERPROFILE%\.file_search_explorer\
```

このフォルダを削除すると、保存された設定や検索インデックスはすべて失われます。

## 注意事項

- 本アプリは Windows 専用です。他のOSでの動作は保証していません。
- 実行ファイル（.exe など）やスクリプトファイルを開く際は、誤操作防止のため
  確認ダイアログが表示されます。
- Windows や Program Files などのシステム関連フォルダは、誤削除防止のため
  重複ファイル検索の対象にできません。
- インデックスを使った検索は、索引作成後に変更されたファイルの反映が
  やや遅れる場合があります。最新の状態にしたい場合は「インデックス管理」から
  更新してください。

## 主なキー操作

| キー操作 | 内容 |
|---|---|
| Ctrl + T | 新しいタブを開く |
| Ctrl + W | 現在のタブを閉じる |
| Ctrl + L | 検索フォルダ欄にフォーカス |
| Ctrl + F | キーワード欄にフォーカス |
| F5 | 検索を実行 |
| Esc | 実行中の検索を停止 |
| PageUp / PageDown | 検索結果を1ページ分スクロール |
| Home / End | 検索結果の先頭／末尾へ移動 |
