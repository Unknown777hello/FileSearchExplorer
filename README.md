# File Search Explorer v0.8.4

Windows向けのデスクトップファイル検索・管理アプリケーションです。
高速なキーワード検索、インデックス検索、重複ファイル検索、内容検索など、
Windowsの標準エクスプローラーでは物足りない検索機能をまとめて提供します。

完全オフライン動作で、外部への通信・テレメトリ・利用状況の送信は一切行いません。

## 動作環境

- Windows 10 / Windows 11（優先動作環境）
- 配布されるインストーラー（standalone build）からのセットアップを推奨します

## 主な機能一覧

- キーワードによるファイル名検索（部分一致・完全一致・正規表現・あいまい検索）
- AND / OR / NOT を使った複数キーワードの組み合わせ検索
- テキスト系ファイルの内容検索（UTF-8 / CP932 / UTF-16 / BOM付きに対応）
- インデックス検索（事前に索引を作成して高速化。SQLite + FTS5利用）
- 拡張子指定・除外拡張子・除外フォルダ・サイズ範囲・更新日時/作成日時範囲による絞り込み
- 複数フォルダの同時検索
- 検索結果のプレビュー表示（テキスト・画像）とハッシュ値計算（MD5/SHA-1/SHA-256）
- 重複ファイル検索（サイズ＋ハッシュ比較による重複検出と安全な削除）
- 検索結果のCSVエクスポート
- お気に入りフォルダ・最近使ったフォルダ・検索条件プリセットの保存
- 検索完了時の通知（音・デスクトップ通知・アプリ内ポップアップ）
- ライト/ダークテーマ切り替え
- インデックスDBの暗号化保存（アプリ終了時に暗号化、起動時に復号）

## 起動方法

配布されているインストーラーを実行し、画面の指示に従ってインストールしてください。
インストール後はスタートメニューまたはデスクトップのショートカットから起動できます。

## データの保存場所

すべてのデータはユーザーのホームディレクトリ配下、以下のフォルダに保存されます。

```
%USERPROFILE%\.file_search_explorer\
├─ settings.json            設定ファイル
├─ settings.json.bak        設定ファイルの直前バックアップ
├─ session_state.json       セッション状態（前回終了時の状態）
├─ app_errors.log           エラーログ
├─ index.db.enc             暗号化されたインデックスDB（通常時）
└─ index.key                インデックスDB暗号化鍵
```

設定ファイル・セッション状態ファイルは、他ユーザーからの読み取りを防ぐため
所有者のみアクセス可能な権限（Windows以外の環境ではchmod 600相当）で保存されます。

## 注意事項

- 本アプリは検索対象のファイル名・パス・キーワードなどの情報を外部へ送信することは一切ありません。
- インデックスDBは通常時は暗号化されて保存され、アプリ実行中のみ復号された状態でディスク上に存在します。
- Windows・Program Files・ProgramData など、システム関連のフォルダに対する完全削除操作は、
  誤操作防止のため意図的に禁止されています。
- 重複ファイルの完全削除はゴミ箱を経由しません。削除前に必ず確認ダイアログの内容を確認してください。
- 不具合や要望は GitHub Issues までお願いします:
  https://github.com/Unknown777hello/FileSearchExplorer/issues

## 主なキー操作

| キー | 動作 |
|---|---|
| Ctrl+T | 新しいタブを開く |
| Ctrl+W | 現在のタブを閉じる |
| Ctrl+L | 検索フォルダ欄にフォーカス |
| Ctrl+F | キーワード欄にフォーカス |
| F5 | 検索を実行 |
| Esc | 実行中の検索を停止 |
| PageUp / PageDown | 検索結果を1ページ分スクロール（大量結果時） |
| Home / End | 検索結果の先頭 / 末尾へ移動（大量結果時） |
