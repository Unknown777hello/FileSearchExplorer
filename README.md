# File Search Explorer

Windows向けのファイル検索・管理アプリです。フォルダを指定してキーワードやファイル内容から目的のファイルをすばやく見つけられます。

バージョン: v0.7.4

## 動作環境

- Windows 10 / Windows 11(64bit)
- インストーラーに必要なファイルがすべて同梱されているため、追加のソフトウェアをインストールする必要はありません

## 主な機能一覧

- キーワード検索(部分一致・完全一致・正規表現・あいまい検索)、AND/OR/NOT対応
- ファイル内容の検索(テキスト系ファイル)
- インデックス検索(事前に索引を作成して高速検索。新規・更新・削除されたファイルだけを対象にした差分更新に対応)
- 通常検索のマルチスレッド処理により、大きなフォルダでも高速に検索
- 検索結果のプレビュー表示(テキスト・画像に加えて PDF・Word・Excel・PowerPoint・音楽・動画にも対応)
- 重複ファイル検索(内容が同じファイルをハッシュ比較で検出。まず簡易チェックで絞り込んでから詳細に比較するため高速です)
- 検索結果は表示されている範囲だけを描画するため、100万件を超える結果でも軽快に操作できます
- 初回起動時にお使いのパソコンの性能を計測し、検索処理を自動で最適化(お好みで後から再計測も可能)
- 前回終了時に開いていたタブ・検索条件の復元
- 検索速度の履歴とグラフ表示(表示のON/OFFは設定で切り替え可能)
- 拡張子・サイズ・更新日時・作成日時での絞り込み、複数フォルダの一括検索
- お気に入りフォルダ・最近使ったフォルダ・検索条件の保存(プリセット)
- ライト/ダークテーマ、検索完了時の通知(音・デスクトップ通知・アプリ内ポップアップ)

## 起動方法

1. インストーラーを実行し、画面の指示に従ってインストールします
2. インストール後に作成されるショートカットから「File Search Explorer」を起動します
3. 初回起動時は、パソコンの性能を計測して検索処理を自動調整するか確認する画面が表示されます。必要に応じて「はい」「いいえ」を選択してください

## データの保存場所

以下のフォルダにアプリの設定やインデックスデータが保存されます。

```
C:\Users\(ユーザー名)\.file_search_explorer\
```

- `settings.json` … アプリの各種設定
- `index.db` / `index.db.enc` … 検索用インデックス(終了時に自動で暗号化されます)
- `session_state.json` … 前回の終了状態
- `app_errors.log` … エラーログ

## 注意事項

- インデックス作成中や自動最適化の計測中はパソコンの負荷が一時的に高くなることがあります
- 重複ファイル検索の「完全に削除する」操作は元に戻せません。削除前に一覧を必ずご確認ください
- Windowsやアプリのシステムフォルダ(Windows、Program Files、ProgramData など)は、誤削除防止のため重複ファイル検索の対象にできません
- 動画・音楽ファイルのプレビューは形式によっては非対応の場合があります
- インデックス検索は索引作成時点の情報を使うため、作成後に変更されたファイルの反映が遅れる場合があります(自動的にバックグラウンドで差分更新されます)

## 主なキー操作

| 操作 | キー |
| --- | --- |
| 新しいタブを開く | Ctrl + T |
| 現在のタブを閉じる | Ctrl + W |
| 検索フォルダ欄にフォーカス | Ctrl + L |
| キーワード欄にフォーカス | Ctrl + F |
| 検索を実行 | F5 / キーワード欄で Enter |
| 検索を停止 | Esc |
