# File Search Explorer

Windows向けのデスクトップファイル検索・管理アプリケーションです。Python / Tkinter で実装されています。

現在のバージョン: **v0.8.6**

## 動作環境

- Windows 10 / 11（優先対応環境）
- 配布形式: スタンドアロンのビルド済みインストーラー（PyInstaller）
- ソースコードから実行する場合は Python 3.9 以降を推奨

## 主な機能一覧

- ファイル名・フォルダ名検索（部分一致・完全一致・正規表現・あいまい検索）
- ファイル内容検索（テキスト系ファイル、UTF-8 / CP932 / UTF-16 対応）
- インデックス検索（SQLite + FTS5 trigram による高速検索、暗号化保存）
- 詳細検索条件（拡張子指定・除外フォルダ・サイズ範囲・更新日時/作成日時範囲）
- 複数フォルダ同時検索、検索条件の保存（プリセット）・お気に入り・最近使ったフォルダ
- 検索結果の絞り込み・列表示切替・CSVエクスポート
- 大量結果に対応した仮想スクロール表示
- 重複ファイル検索（ハッシュ比較）
- ファイルプレビュー（テキスト/画像）、ハッシュ値計算（MD5/SHA-1/SHA-256）
- 検索完了通知（音・デスクトップ通知・アプリ内ポップアップ）
- 検索速度履歴の記録・表示
- ライト/ダークテーマ

## 起動方法

配布されているインストーラーを実行し、インストール後にスタートメニューまたはデスクトップのショートカットから起動してください。

## データの保存場所

すべてのデータはローカル環境のみに保存されます。外部への通信は一切行いません。

```
%USERPROFILE%\.file_search_explorer\
├── settings.json          設定ファイル
├── session_state.json     セッション状態
├── index.db / index.db.enc  検索インデックス（暗号化して保存）
├── index.key               インデックス暗号化キー
└── app_errors.log           エラーログ
```

設定ファイル・インデックスDB・暗号鍵はいずれも所有者のみ読み書き可能な権限に制限されます。

## 注意事項

- 本アプリは完全オフラインで動作します。ファイル情報・検索キーワードなどが外部へ送信されることはありません。
- Windows・Program Files など、システム関連フォルダへの削除操作は安全のためブロックされます。
- 実行ファイル・スクリプト（.exe / .bat / .ps1 など）を開く際は確認ダイアログが表示されます。

## 主なキー操作

| キー | 動作 |
|---|---|
| Ctrl+T | 新しいタブを開く |
| Ctrl+W | 現在のタブを閉じる |
| Ctrl+L | 検索フォルダ欄にフォーカス |
| Ctrl+F | キーワード欄にフォーカス |
| F5 | 検索を実行 |
| Esc | 検索を停止 |

## v0.8.6での変更点（起動処理・起動速度）

1. `cryptography` の導入有無チェックを、実 import を伴わない軽量な判定方式に変更
2. 起動時のセッション状態保存をバックグラウンドスレッド化し、メイン処理をブロックしないよう変更
3. 起動時の設定ファイル読み込みを1回に統合（従来は2回読み込んでいた）
4. UIフォント判定結果のキャッシュ不具合を修正（環境によっては毎回フォント列挙が走っていた問題を解消）
5. 「最近開いたファイル」メニューの構築を、実際に開かれるタイミングまで遅延

いずれも既存の機能・UIの見た目には影響しません。
